# Phonebook App

A simple phonebook application built with Node.js and Express.

## Features

- Add new contacts with name and phone number
- View all contacts
- Delete existing contacts
- Search contacts by name

## Live Demo

The application is deployed and available at: https://phonebook-mnhk.onrender.com/

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

## API Endpoints

- `GET /api/persons` - Get all contacts
- `GET /api/persons/:id` - Get contact by ID
- `POST /api/persons` - Add new contact
- `DELETE /api/persons/:id` - Delete contact

## Technologies Used

- Node.js
- Express.js
